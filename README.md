# Клуб по настолни игри – Уеб сайт

## Описание на проекта
Този уеб сайт представя училищния клуб по настолни игри.  
Целта е да информира ученици, родители и учители за дейностите, събитията, целите и атмосферата в клуба.  
Сайтът включва начална страница, информация за клуба, събития, галерия и форма за записване.
